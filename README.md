# ՀՀ Սահմանադրությունների համեմատություն

Статическое двуязычное приложение для текстового сравнения Конституции Армении и опубликованного проекта. Армянский выбран по умолчанию. Переключатель языка меняет интерфейс, обе версии документов и PDF, на которые ведут ссылки.

## Источники

| Файл | Что сравнивается | Официальный источник |
| --- | --- | --- |
| `sources/old.pdf` | Действующая армянская редакция с 26.06.2020. 66 страниц, 16 глав, 220 статей | [ARLIS](https://arlis.am/hy/acts/143723/latest) |
| `sources/new.pdf` | Армянский проект, опубликованный 23.11.2026. 176 страниц, 12 глав, 89 статей | [Портал проекта](https://yourconstitution.am/) |
| `sources/old_ru.pdf` | Предоставленный русский текст редакции 2015 года. 48 страниц, статья 213 приведена в редакции до поправки 2020 года | Исходный PDF в разделе «Источники» |
| `sources/new_ru.pdf` | Предоставленный рабочий перевод проекта. 46 страниц, 12 глав, 89 статей | Исходный PDF в разделе «Источники» |

В русском режиме показано предупреждение о редакции статьи 213 и статусе перевода. Русский diff построен по предоставленным русским PDF. Проверенные соответствия статей основаны на армянских текстах. Все четыре источника проверяются по SHA‑256.

## Локальный запуск и сборка

Нужен Node.js 22.18+ из поддерживаемой LTS-ветки. Для установки зависимостей нужен доступ к npm.

```sh
npm install
npm run dev
npm run build
npm run preview
```

После `npm run preview` откройте [http://localhost:4173](http://localhost:4173). Браузер блокирует загрузку модулей приложения, если открыть `dist/index.html` через `file://`.

Готовую папку `dist` можно открыть по HTTP без установки npm-пакетов. Из корня проекта запустите команду ниже и откройте [http://127.0.0.1:4173](http://127.0.0.1:4173).

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

`dev` и `build` автоматически выполняют `prepare:data`. При генерации создаются четыре структурированных документа в `generated/documents/`, поисковые данные и фрагменты diff. Сборка использует уже подготовленный Markdown и исходные PDF. Poppler и OCR для обычной сборки не нужны.

## Извлечение и проверка

Для повторного извлечения нужны Python 3.9+ и Poppler с командами `pdfinfo` и `pdftotext`. Для опционального OCR нужны `pdftoppm`, Tesseract и языковые пакеты `hye` и `rus`. Установку языка можно проверить командой `tesseract --list-langs`.

```sh
npm run extract
npm run check:extraction
npm test
```

Для попытки OCR на страницах со слабым текстовым слоем используйте `npm run extract -- --ocr`. Такие страницы попадают в отчёт с требованием ручной сверки. Переданные PDF имеют читаемый текстовый слой на всех страницах, поэтому OCR не использовался.

Скрипт сохраняет Markdown обеих языковых версий в `content/old.md`, `content/new.md`, `content/old_ru.md` и `content/new_ru.md`. Он сводит физические строки в абзацы, восстанавливает разорванные числовые окончания и убирает обрамление публикации и повторяющиеся колонтитулы. Внутренние знаки препинания сохраняются. Неоднозначный перенос со знаком дефиса остаётся в тексте и в отчёте. Заголовки глав, статьи, пункты и подпункты разбираются по структуре, а ссылки на статьи открывают страницы оригинала.

[Отчёт извлечения](content/extraction-report.json) содержит число страниц, номера страниц статей, SHA‑256 источников и Markdown и список обнаруженных проблем. Проверка сверяет ожидаемую последовательность статей и глав, число PDF-страниц, читаемость армянских символов и состав непробельных символов в извлечённом тексте. Эти проверки дополняют визуальную сверку с оригиналом. При обновлении PDF или алгоритма просмотрите отчёт и diff извлечённого текста.

## Как устроено сравнение

Оглавление и поиск в боковой панели работают по тексту проекта. При выборе статьи обе редакции доступны в сравнении.

- **Git Diff** сохраняет порядок обоих документов. Похожие абзацы выравниваются с учётом общих слов, фраз и проверенных соответствий статей. В выровненной паре подсвечиваются изменившиеся слова, а общий текст отображается нейтрально. Определение равенства учитывает нормализованные пробелы и Unicode. На экране сохраняется текст соответствующей стороны. Большие фрагменты подгружаются при переходе, исходные тексты статей и индекс поиска загружаются по запросу.
- **По статьям** использует [article-mappings.json](content/article-mappings.json). Записи привязаны к контрольным суммам PDF и снабжены проверяемым текстовым основанием из двух источников. Одна статья может указывать на несколько статей проекта. Статус переноса используется для сохранённой формулировки с новой нумерацией и возможными типографическими отличиями. Частичное совпадение явно обозначается.
- Данные сопоставления покрывают часть статей. Для остальных интерфейс показывает исходный текст и статус «Соответствие не установлено». Подтверждённых добавлений и удалений в текущем наборе нет. Статистика учитывает проверенные статусы, а число неустановленных соответствий включает статьи обеих версий. Текстовый diff сам по себе не пополняет этот набор.

Чтобы расширить проверенный набор, добавьте запись с идентификаторами из `generated/documents/`, основанием для попарной сверки и переводом основания в `src/locales/hy.json` и `src/locales/ru.json`. Указывайте `scope: "partial"`, если в паре совпадает только часть текста или предмета статьи. После внесения изменений выполните `npm test` и `npm run build`.

## Публикация

- **GitHub Pages**. Соберите `npm run build` в GitHub Actions и передайте `dist/` в качестве артефакта Pages, затем выполните его деплой через `actions/deploy-pages`. В настройках Pages выберите источник **GitHub Actions**. Относительный базовый путь поддерживает размещение под именем репозитория.
- **Cloudflare Pages**. Подключите репозиторий, задайте `npm run build` как команду сборки и `dist` как каталог публикации. Выберите Node.js 22 или 24. Готовый `dist` также можно загрузить через Direct Upload.

Переходы к статьям используют фрагмент URL, поэтому правила перенаправления SPA не требуются. Шрифт Noto Sans Armenian размещается вместе со сборкой. [Лицензия шрифта](public/OFL-NotoSansArmenian.txt).
